## 🎯 项目简介

一个用 **"养宠物"** 来陪伴你完成目标的打卡应用。

最初我想用 **"卡路里超标 → 宠物变胖"** 做强反馈——但在 PM 视角的方案评审里，我推翻了自己：

> **减肥用户已经被现实惩罚够了。**

最终改为 **"任务完成度 → 宠物升级 / 解锁服装"** 的全正向机制：

* 🐱 完成任务 → 宠物升级、解锁新服装
* ⏱️ 番茄钟专注 → 宠物元气满满
* 🎁 正向反馈 → 坚持得下去

### ✨ 设计要点

* 💛 **情感化设计**：把冷冰冰的打卡变成有温度的陪伴
* ➕ **全正向反馈**："不伤人的反馈，比反馈本身更重要。"
* 🔄 **用户研究驱动**：方案评审中推翻自己的强反馈设计
